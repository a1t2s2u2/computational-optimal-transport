# エントロピー正則化 OT・ε極限収束の数値デモ

セミナー ch04（エントロピー正則化）の **正則化パラメータ ε の極限による収束**
（定理 `thm:sem-entropic-convergence-eps-zero`, Thm 4.13）を、実際に計算して体感する
自己完結スクリプト。

検証する3つの主張：

| | 主張 | このデモでの確認 |
|---|---|---|
| **(i)** | `lim_{ε→0} MK^ε_C(a,b) = MK_C(a,b)` | 1D 例で `⟨C,P_ε⟩` と `MK^ε_C` が真の OT 値へ。ギャップ → 0 |
| **(ii)** | `P_ε → argmax_{P∈S*} H(P)`（ε→0） | 最適解が複数ある退化3×3例で、最大エントロピー最適解 `P*` へ収束 |
| **(iii)** | `P_ε → a bᵀ`（ε→+∞） | 1D 例で独立カップリングへ収束（`‖P_ε − a bᵀ‖₁ → 0`） |

## 計算の中身

- `P_ε` は命題4.9（`prop:sem-entropic-scaling-form`）のスケーリング形
  `P_ε = diag(u) K diag(v)` を満たす `u, v` を、**行列スケーリング反復**
  （周辺分布を交互に合わせる反復。実体は Sinkhorn）で求める。
  数値安定のため **log-domain**（log-sum-exp）で実装しており、小さい ε でも
  `K = exp(-C/ε)` のアンダーフローを避けられる。
  ※ 反復の収束率の理論（Hilbert 計量・Birkhoff, ch05）は本デモのスコープ外。
- 真の OT 値 `MK_C`（(i) の比較対象）は外部ソルバを使わず純 numpy で厳密に：
  - 1D・凸コストでは**単調カップリング**（北西コーナー則）が最適なのでそれを使う。
  - 退化3×3（`a=b=1/3`）では頂点＝(1/3)·置換行列を全探索する。
- 退化例の最大エントロピー最適解は解析的に既知：
  ```
  P* = [[1/6, 1/6,  0 ],
        [1/6, 1/6,  0 ],
        [ 0 ,  0 , 1/3]]
  ```
  これに `P_ε` が（機械精度で）収束することを確認する。

## 実行

```bash
# numpy + matplotlib があれば数値レポート + PDF 図を生成
python3 entropic_ot_demo.py

# matplotlib 無し / 図不要なら数値レポートのみ
python3 entropic_ot_demo.py --no-plots
```

主なオプション：`--n --m`（1D ヒストグラムのサイズ, 既定50）,
`--eps-min --eps-max --n-eps`（ε 掃引）, `--output-dir`（図の出力先, 既定 `./out`）。

## 出力

- **コンソール**：(i)(ii)(iii) の数値検証表と、スケーリング形・周辺分布のサニティチェック。
- **PDF 図**（`out/` に生成。`out/` は `.gitignore` 済みなので実行ごとに再生成）：
  - `eps_sweep_plans.pdf` … `P_ε` のヒートマップ列。ε→0 で真の OT へ鋭く、ε→∞ で rank-1 `a bᵀ` へ。
  - `cost_entropy_vs_eps.pdf` … コスト・正則化値・エントロピーの ε 依存。
  - `maxent_selection.pdf` … 退化3×3 で `P_ε → P*`。

## 依存

`numpy`（必須）、`matplotlib`（図出力時のみ・任意）。
